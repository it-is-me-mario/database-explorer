# Repository instructions

Read `doc/maintenance/README.rst` before changing pages, data pipelines or deployment.
Preserve source licences, attribution, classifications and observation boundaries.
Never publish raw source databases, credentials or local source paths.
Distinguish native totals, identified goods, goods proxies and Comtrade references.
Do not silently turn missing data into zero, disaggregate a regional aggregate,
substitute a neighbouring year, or treat a difference as an accuracy score.
Run the relevant Python/Node checks, strict Sphinx build and link/download checks.
Verify the deployed commit and public pages after publication.
