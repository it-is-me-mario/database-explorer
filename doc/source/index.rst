MARIO Database Explorer
=======================

Explore database classifications, compare published indicators and inspect
bilateral trade. Each observation retains its source, year, units and scope.

The Python library and its API documentation remain at
`marioproject.com <https://www.marioproject.com/en/latest/>`_.
